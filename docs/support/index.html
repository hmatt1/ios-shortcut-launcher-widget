Shortcut Launcher Widget — Support

The widget is empty / just says "Edit Widget"

Long-press the widget → Edit Widget → pick one or more Shortcuts under Shortcuts. The number you pick is the number of tiles — there's no separate count to set.

I can't select the Extra Large size

Extra Large needs iOS 27. If you're on iOS 27 and it's still not selectable, make sure you're running the latest build — this was a known issue in earlier betas.

How do I change the look?

Open the app. Swipe in from the left edge (or tap the stack icon) for presets, from the right edge (or tap the palette icon) for themes. Presets bundle a density, column count, background, and theme together; themes are just colors, reusable across presets.

How do I blend the widget into my wallpaper?

In a preset, set Background to Transparent, then upload a screenshot of your own wallpaper. Pick the same Home Screen position in the widget's own Position setting so the crop lines up.

Does this app collect any data?

No — see the Privacy Policy. No accounts, no network access, no analytics.

Something else

Open an issue on GitHub — that's the fastest way to reach the developer.
